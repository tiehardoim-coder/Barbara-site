# Bárbara Fraulob — site estático

Site de psicologia clínica de Bárbara Fraulob (Campo Grande/MS e online).

Hospedado permanentemente via GitHub Pages.

**Para ativar o site:**
1. Vá em Settings > Pages
2. Source: Deploy from a branch
3. Branch: main / root
4. Salve.

O site ficará em https://tiehardoim-coder.github.io/Barbara-site/

Depois você pode apontar um domínio customizado.
